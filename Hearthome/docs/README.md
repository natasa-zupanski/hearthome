# docs/

Design documentation for Hearthome. All files here are produced during BDD sessions — no code lives here.

## Contents

| Path | Purpose |
|---|---|
| `SoftwareRequirements.md` | Read-only requirements reference. Consulted during discovery but never modified. |
| `features/` | Gherkin feature files — one per feature, produced during BDD sessions. |
| `decisions/` | Architecture Decision Records (ADRs) — one per non-trivial design decision. |

## BDD Session Process

Each session runs through five steps — Discovery, Acceptance Criteria, Scenarios, Design Checkpoint, and Handoff — and ends before any code is written.
